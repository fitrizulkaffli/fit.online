# Fit Online (2015)
Fit Online was my very first website, designed and developed as part of ICT coursework. This project marks the beginning of my journey into web design and development.

## Purpose
The GitHub Pages version serves portfolio purposes, showcasing my earliest web design and development work. This project was never published publicly and was submitted offline for educational purposes.

## Technologies Used

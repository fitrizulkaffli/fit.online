# Personal Website (2015)

Archived personal website, my first-ever website, developed as part of ICT coursework for the Malaysian Higher School Certificate. The project was a hobby-focused website developed using Adobe Muse, Adobe’s now-deprecated website builder.

The website was never published publicly and has no official domain. The project was submitted offline for educational purposes. It is uploaded here for historical record and to showcase my very first web design and development work.
